## Modbus TCP 0.2.1

> 沿用商店已登记的插件 ID：`io.github.yuzhi.modbus`（发布者 `yuzhi`），
> 因此这是对 0.1.0 的就地升级，不会变成第二个插件。

### 中文更新说明

**写入只在回车时下发**

双击保持寄存器或线圈单元格，输入新值，按 `Enter` 才真正写下去。按 `Esc` 取消，点击别处（失去焦点）同样取消——离开单元格永远不会写寄存器。取消时会有提示，双击后什么都没改也不会写入。

**工作区自己配置自己**

新建连接只问一个「工作区名称」。host、端口、从站号和超时都属于工作台里添加的设备；一个连接都不建、直接打开工作台也照常可用（标题栏显示 `standalone`）。

**改完定义立刻生效**

新建地址范围默认读取 10 个地址。改设备、区域、起始地址、数量或数据类型都会自行发起读取，不用再点一次「读取」或「轮询」；数据类型变宽会自动补读缺少的寄存器，不会留下半格空白。改设备的 host、端口或超时会自动重连。

**其它**

- 安装包根目录带上 `LICENSE`（MIT）
- 描述里点明连接目标：你填写的 host:port，端口默认 502
- 从 manifest、两份 README 和商店文案里删掉「写入需要二次确认」这条不实描述——从来不需要

### English

This release is published under the plugin id the store already lists — `io.github.yuzhi.modbus`, publisher `yuzhi` — so it upgrades an existing 0.1.0 install instead of appearing as a second plugin.

**Writes only send on Enter**

Double-click a holding register or coil, type, press `Enter`. `Esc` cancels, and so does clicking anywhere else: leaving the field can never write a register. A dropped edit says so in a toast, and a double-click that types nothing writes nothing.

**A workspace configures itself**

Creating a connection asks only for a workspace name. Host, port, slave id and timeout belong to the devices added inside the workbench, and a workbench opened with no connection at all still works (`standalone` in the header).

**Editing a definition takes effect on the spot**

A new range reads ten addresses. Changing the device, area, start address, quantity or data type issues the read by itself — no second press of Read or Poll — and a wider data type fetches the extra registers instead of leaving half the grid blank. Editing a device's host, port or timeout re-dials the session.

**Also**

- The package carries `LICENSE` (MIT) at its root
- The description names the connection target: the host and port you enter, port 502 by default
- Removed from the manifest, both READMEs and the store copy: the claim that writes needed a second confirmation. They never did.

### 安装 / Install

下载对应平台的 `.dbxp`。从 0.1.0 升级会就地替换插件。0.1.0 创建的连接带着新连接表单已不再声明的 host/port 字段，请删掉那些连接，改为新建一个工作区。

Download the `.dbxp` for your platform. Upgrading from 0.1.0 replaces the plugin in place. Connections created by 0.1.0 carried host/port fields that the new connection form does not declare, so delete those and create a workspace instead.
