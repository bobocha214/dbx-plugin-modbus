# 0.2.3

## 0.2.3 更新

地址表格改为 Modbus Poll 式布局：

- 行数（Rows）成为唯一的布局设置，列数自动 = 值数量 ÷ 行数
- 数值按列优先排布：第 i 个值位于第 `i % rows` 行、第 `⌊i / rows⌋` 列，
  地址为 `start + i × 寄存器数`
- 取消翻页，改为整表滚动；同一个地址永远待在同一个格子里
- **每个值都带地址**：格内左侧是该值的地址（00000 样式），右侧是值，
  不必再按偏移量心算；表头仍是各列的基址
- 主显示格式仍是值，双击保持寄存器 / 线圈可内联写入（回车才发送）
- 表格按内容收缩，不再被拉伸到整个面板宽度，地址与值都收紧到刚好容纳内容

新增「通信报文」面板（顶栏「报文」按钮）：

- 每次读写的完整发送（TX）与接收（RX）报文原样显示（十六进制，含 MBAP 头）
- 每行标注从站号与功能码；设备返回异常时显示异常码
- 与「读取日志」共用抽屉，双 Tab 切换，上限 400 条

换成官方 Modbus 图标（512×512 矢量 SVG，透明背景，只有中央的齿轮图形与蓝色字标，没有底板）。

## 0.2.3

- **Modbus Poll layout.** The register sheet is a real table: `Rows` is the only
  layout setting, columns follow as `values / rows`, values fill down each column,
  and paging is gone, so an address never moves between cells. Every cell carries
  its own address — address on the left, value on the right — so no offset has to
  be counted, and the header still names each column's base address. The sheet
  sizes to its content instead of stretching across the pane.
- **New icon.** The official Modbus mark as a 512×512 vector SVG: the gear and
  the blue wordmark on a transparent background, with no tile behind them.
- **Communication view.** The new `Frames` button opens a drawer that shows the
  complete TX and RX bytes of every read and write, labelled with the slave id
  and function code, or the exception code when the device rejected a request.
- Inline writes are unchanged: double-click a holding register or coil, type,
  press `Enter`. `Esc` or leaving the field cancels.
